# Миграции базы данных

- Миграции `*.up.sql` применяются в порядке имён.
- Уже опубликованный или применённый SQL-файл нельзя редактировать.
- Любое изменение схемы добавляется новым файлом с возрастающим шестизначным номером.
- Миграции должны быть совместимы с поддерживаемыми версиями PostgreSQL 14–18.
- Опасные удаления таблиц, столбцов или пользовательских данных требуют отдельного подтверждения.
